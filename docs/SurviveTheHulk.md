# Rift Hub · Survive The Hulk

The **Hub → Survive The Hulk → Execute** card opens the full script from [Rift-Hub-Survive-The-Hulk](https://github.com/copperpoppercms-sys/Rift-Hub-Survive-The-Hulk) and closes the universal hub. Join the game first. A failed download keeps the hub open; a failed startup cleans up the Hulk window and reopens the hub.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/copperpoppercms-sys/Rift-Hub-Survive-The-Hulk/main/main.lua"))()
```

Game: [Survive The Hulk](https://www.roblox.com/games/109166720609444), place `109166720609444`, universe `10742937135`. The card uses the game's published icon. `games/survive-the-hulk.lua` forwards to its standalone repository.

Download [the full editable HTML](https://github.com/copperpoppercms-sys/Rift-Hub-Survive-The-Hulk/blob/main/docs/SurviveTheHulk_Editor.html), open it in a browser and use Copy all code. Script changes and tests are maintained in the standalone repo.
